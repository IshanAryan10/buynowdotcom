# BuyNowDotCom

Spring Boot E-Commerce Backend Project

## Features
- User Management
- Product Management
- Category Management
- Cart Management
- Image Uploads

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Setup

1. Copy:

```text
application.properties.example
```

to

```text
application.properties
```

2. Update:

```properties
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

3. Run:

```bash
mvn spring-boot:run
```
